# Blocky FPS Game

A blocky first-person shooter game inspired by Roblox, built with Three.js.

## Features

- **First-person shooter gameplay** - Navigate a blocky world and eliminate enemies
- **Enemy AI** - Red cube enemies that hunt and chase the player
- **Shooting mechanics** - Click to shoot with ammo management
- **Health system** - Track your health as enemies damage you
- **Score tracking** - Keep track of your kills
- **Blocky environment** - Roblox-style cubic buildings and terrain

## Controls

- **WASD** - Move forward/backward/left/right
- **Mouse** - Look around (click to lock cursor)
- **Click** - Shoot enemies
- **R** - Reload ammo

## How to Play

1. Open `index.html` in a modern web browser
2. Click to lock your mouse cursor
3. Use WASD to move around the map
4. Aim with your mouse and click to shoot red enemies
5. Defeat enemies to earn kills
6. Avoid taking damage from enemies
7. Press R to reload ammo (30 rounds)
8. Game ends when health reaches 0

## Game Mechanics

- Player starts with 100 health
- 5 enemies spawn on the map that chase the player
- Each enemy takes 2 shots to defeat (25 damage per shot)
- When an enemy is defeated, a new one spawns
- Enemies deal damage if they get too close
- Ammo is limited to 30 rounds per magazine
- Fog effect shows distance limiting in the world

## Technologies Used

- **Three.js** - 3D graphics rendering
- **Vanilla JavaScript** - Game logic and mechanics
- **WebGL** - Hardware-accelerated rendering

## Installation

1. Clone this repository
2. Open `index.html` in a web browser
3. Start playing!

No installation or build process required - it's a pure JavaScript game.

## Performance Tips

- Works best in Chrome, Firefox, and Edge
- Adjust renderer resolution if experiencing lag
- Recommended for desktop/laptop play
- Mouse lock is required for optimal gameplay
